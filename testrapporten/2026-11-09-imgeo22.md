# 2026-11-09 — IMGeo 2.2 omgezet naar begrippenkader

De skill uitgevoerd op het UML-model IMGeo 2.2 uit het register
(`register.geostandaarden.nl/informatiemodel/imgeo/2.2/IMGeo.xmi`), inclusief
SHACL-validatie, inhoudelijke review, vergelijking met het gepubliceerde
IMGeo-kader en een vergelijking van de vier in de agent beschikbare
chatmodellen (alleen het grootste model is daadwerkelijk uitgevoerd; de andere
drie zijn op documentatie vergeleken).

## Resultaat

- 393 begrippen: 38 objecttypen, 67 attributen, 4 datatypen, 284 waarden; 57 collecties; 3.686 triples
- SHACL (NL-SBB-profiel 1.0.0 + extensie): run B met context 13 Violations (closeMatch naar externe concepten zonder skos:Concept), 180 Warnings (o.a. 72 verweesde begrippen zonder semantische relatie), 2 Info
- Review: 384 ok, 9 definitie-bevindingen (identieke brondefinities bij de vier "op talud"-attributen en bij reclamebord/reclamezuil)
- Vergelijking met het gepubliceerde IMGeo-kader (464 begrippen, opgehaald via `upload.begrippenxl.nl/storage/imgeo/imgeo.ttl`; de REST-endpoint gaf HTTP 403): 444 van 464 gematcht (273 op URI, 168 op term+definitie, 3 term/andere definitie, 20 geen match); definitie gelijk bij 433 van 444
- Alle 7 beslispunten zijn zonder bevestiging overgenomen (`werk/aannames.md`)
- Termcorrecties gedocumenteerd in `reports/rapport.md` sectie 7: vaste termen, samenstellingen, de attribuuttermcorrectie `plus-fysiekVookomen` -> `fysiek voorkomen`, prefixen `bgt-`/`plus-`, hernoeming `niet-bgt` -> `niet-BGT-object` en de waarden-splitsingen voor `onverhard`/`zand`; de review gaf 0 term-veroordelingen
